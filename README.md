### KLORIS- WEBAPPLICATION FOR POTATO DISEASE CLASSIFICATION

Potato is an extensively cultivated crop plant by farmers. It is prone to fungal diseases late blight and early blight which causes huge losses to farmers and sometimes damage to the entire crop plant. 
Here we develop a web based application which is capable of recoginition and prediciting accurate diagnosis to the Disease. 

The model is built in three layers-
1. A CNN capabale of diagnnosing the diease and predicting output
2. A Fast API and React JS network
3. Web based application deployed on google cloud paltforms for accesibilty without needing a server on your computer
4. A mobile app
